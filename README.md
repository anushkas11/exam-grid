Exam Grid

Exam Grid is a full-stack exam seating management system built using React, Spring Boot, and MySQL.

Technology Stack:
- Frontend: React, Vite, JavaScript
- Backend: Java, Spring Boot
- Database: MySQL
- Build Tool: Maven

Project Structure:
- examgrid-frontend: React frontend
- examgrid-backend: Spring Boot backend

The project is designed to manage examination seating arrangements.
